# Notion DB 参照（共通）

Notion の Data Source ID・プロパティ定義を一元管理する。変更時はここだけ直す。

## 対象 DB

| DB | Data Source | 主キー |
| --- | --- | --- |
| プロジェクト | `collection://3539ca7d-99dc-8089-94c2-000bde50955a` | プロジェクトNo.（PRJ-N 自動採番） |
| タスク | `collection://3539ca7d-99dc-808f-833e-000b24ce030c` | ID（TSK-N 自動採番） |

タスク DB の `プロジェクト` プロパティ（リレーション）で TSK を PRJ に紐付ける。

## プロパティ定義（適用済み）

### プロジェクト DB

- `ステータス`: 未着手 / 進行中 / 完了
- `種別`（select）: システム開発 / 創作 / 調査 / 運用 — Phase 2 で設定
- 本文テンプレ「新規プロジェクト」: 一行サマリ / 背景・目的 / 要求 / 成果物〔作業・創作・システム要件〕/ スコープ / 制約 / 完了条件 / 関連資料 / タスク分割 / 未確定事項

### タスク DB

- `ステータス`: 未着手 / 進行中 / 完了
- `重要度`: HIGH / MIDDLE / LOW
- `規模`（select）: S=些細 / M=1〜2 ファイル / L=通常 — skill-workflow の圧縮ルール判定材料。Phase 3（計画）で設定
- `PR`（URL）: 評価フェーズで PR URL を書き込む
- 本文テンプレ（見出し固定）: 一行サマリ / 背景・動機 / 完了条件 / スコープ外 / 制約 / 関連資料 / 不明点・迷い
- 既定テンプレのスプリント紐付けは解除済み（新規タスクはスプリント未割当で作成）
