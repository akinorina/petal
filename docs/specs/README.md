# specs（アーカイブ）

このディレクトリは、**タスク単位（TSK-N / PRJ-N）で時系列に積み上がった設計メモのアーカイブ**です。

- ドキュメントは [docs/](../) 直下のカテゴリ別ドキュメント（`00_overview` / `10_architecture` / `20_features` / `30_operations` / `40_processes`）に**再編済み**です。まずは [docs/README.md](../README.md) を起点に読んでください。
- ここにあるファイルは、各機能・設計の**背景・経緯の一次記録**として残しています。新ドキュメントから「原典」としてリンクしています。
- 番号接頭辞は着手順であり、機能・レイヤーの体系を表しません。

> 現状の実装仕様は再編後のドキュメントを正とします。本ディレクトリの記述は作成時点のもので、現状と差異がある場合があります。

再編の方針・新旧対応表は [documentation-plan.md](documentation-plan.md)（本ディレクトリ内・アーカイブ）を参照。

## diagrams

図は [diagrams/](diagrams/) にあります。再編後の各カテゴリ（`docs/*/diagrams/`）にも関連図を複製配置しています。
