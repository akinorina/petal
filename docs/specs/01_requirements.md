# Petal - 要求仕様書

## 1. プロジェクト概要

**Petal** は、ユーザーごとに画像コンテンツをアップロード・管理できるWebアプリケーションです。
Instagramのような画像コンテンツ管理を念頭に置きつつ、将来的な機能拡張の土台となるシステムを目指します。

### 目的

- 画像コンテンツのアップロード・閲覧・管理
- 認証によるユーザーごとのコンテンツ管理
- 開発者（仲田明紀）のフルスタック・クラウド技術の習得

---

## 2. ユーザーとロール

| ロール | 説明 |
| ------ | ---- |
| 管理者（Admin） | ユーザーの登録・編集・削除を行う。システム全体を管理する。 |
| 一般ユーザー（User） | ログイン後、自分のコンテンツを管理できる。 |

- ユーザーは複数存在する。
- アップロードされたコンテンツは **登録したユーザー本人のみ** 閲覧できる（プライベート）。
- 将来的に、コンテンツの一般公開機能を追加する可能性がある。

---

## 3. 機能要件

### v1（MVP）― ユーザー管理と認証

| # | 機能 | 概要 |
| - | ---- | ---- |
| 1 | ユーザー登録 | 管理者がユーザーを作成する |
| 2 | ユーザー編集 | 管理者がユーザー情報を更新する |
| 3 | ユーザー削除 | 管理者がユーザーを削除する |
| 4 | ログイン | メールアドレス＋パスワードで認証する |
| 5 | ログアウト | セッションを終了する |

### v2以降 ― コンテンツ管理

| # | 機能 | 概要 |
| - | ---- | ---- |
| 6 | 画像アップロード | 画像ファイルをクラウドストレージに保存する |
| 7 | 画像一覧表示 | ログインユーザー自身の画像を一覧で表示する |
| 8 | 画像詳細表示 | 個別の画像の詳細情報を表示する |
| 9 | 画像ダウンロード | 画像ファイルをダウンロードする |
| 10 | 画像削除 | アップロードした画像を削除する |

### 将来構想

- OAuth 認証（Google / GitHub）
- コンテンツの一般公開設定
- 通知機能
- LLM API（Claude / ChatGPT / Gemini）を活用したAI機能
- 音声などの他コンテンツへの対応
